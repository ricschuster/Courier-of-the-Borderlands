## Decisions taken

1. **Tier CI by risk, and skip only what provably cannot matter.** The rule is a
   tested module, not YAML shell, because a wrong "skip" is silent.
2. **No merge queue.** Branch protection is `strict: false`, so there is no
   rebase-and-retest churn for one to fix. Measuring killed the idea before it
   cost anything.
3. **Demanding loses its repair premium, not its teeth** (#424).
4. **Target 2 hours, build for 25 to 30 minutes first.** A web topology, not the
   current chain. Core arc plus optional side work.
5. **Gate shortcuts, never access.** This revises `07_roads_gate_the_wagon.md`.
   Terrain locks leave a longer way round and stay; exit locks are invisible
   walls and go.
6. **Failure must be cheap**, or the soft gate teaches "never explore".

## The three findings

### CI was one step, not a suite

`check` (eslint, tsc, 1270 unit tests with coverage, production build) runs in
**36 seconds**. The `e2e` job took 5m48, of which **5m00 was the spec run**: 500
test-seconds of real-time driving on 2 workers. That cost is intrinsic and can
only be spread, not optimised.

The waste was elsewhere: `ci.yml` had no path filters at all, so a one-file docs
PR paid 5m54, and the release-please PR paid the same on **every merge** for a
CHANGELOG bump.

Note the shape of the fix, because it recurs: `e2e` is a required check, so it
cannot be skipped or `paths-ignore`d. A skipped required check never reports and
blocks the merge forever. The job must run and guard its own steps, and a matrix
must hide behind an aggregator that owns the required name.

### Deploy follows main, not the release

`deploy.yml` triggers on CI success on `main`. The 0.9.0 tag was held for a day
while every change in it was already live. Verified against the deployed bundle
rather than reasoned about: it contained both the fixed Wayfinder description
and the Reinforced Wheels gate.

v42's "three player-visible changes are now unreleased" was true only in the
tagging sense, which is the sense that does not matter to a player. **Anything
merged to `main` is in front of users within minutes.**

### The exit lock was a toll on a paved road

#434 committed to measuring whether the wilds could gate the road out instead of
the lock. They cannot:

- Greybridge row 8 is road end to end, and the Fenmarch gateway sits at the foot
  of an unbroken road down column 21. Leaving the hub costs about **1.8
  condition** against a 25-point tank.
- Reinforced Wheels is `speedBonus: 0.25` with **no roughness relief**. It never
  helped anyone survive anything.

So the gate was a 50c toll on a paved road, and removing it reopens #362's hole.
That is accepted deliberately and tracked as #436, not overlooked.

## Verification notes

- **Eight neutralizations across five PRs**, each watched failing before
  restoring. Every one produced the expected failure, so no new coverage holes
  turned up; the guards were written alongside the code rather than after it.
- **The one real bug I shipped and caught was my own.** The shard aggregator,
  written first as a shell block, read a crashed `scope` job's empty output as
  "out of scope" and reported a pass with the browser suite never having run.
  That is the same silent-pass shape #420 was written to prevent. Moving it into
  a tested module is what surfaced it.
- **#424 was measured, not asserted.** `travel-sink-measure` over a full arc,
  before and after: strand events **10 -> 2**, samples at zero condition **16 of
  86 -> 4 of 85**, arc duration **8.4m -> 4.5m**. Total wear went *up* (254 ->
  408) because wear floors at zero, so the broken profile accrued less by being
  already broken.
