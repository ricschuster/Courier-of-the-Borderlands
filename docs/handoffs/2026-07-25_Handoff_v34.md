  `.nojekyll` is all that remains. 86 dead directories (146 files) were removed

- **#365 -> PR #369: first extraction out of `map-scene.ts`.** 2326 -> 2218

  bookkeeping, and fog rectangles; new `src/systems/tile-geometry.ts` holds the
  one pure piece (`tileCenter`) with unit tests.

## Decisions taken

1. **The gold roles stay named apart.** Four concepts share one value today (who
   the courier is, which settlements have answered, what the UI wants you to
   click, what a payout looks like). Collapsing them into one constant would have
   made the next colour change worse, so the palette entry is named once and the
   roles derive from it.
2. **The preview leak was fixed at source, not pruned on a schedule.** #366
   offered either. A per-close step is precise and self-healing; a cron prune
   would have been a second thing to maintain. The guard on `.nojekyll` is what
   makes the delete safe.
3. **#365 took the tile cluster, not the panel cluster the issue recommended.**
   The issue argued the panel-refresh methods would yield pure testable logic.
   They will not: `panel-text.ts` already holds those builders, and what remains
   in the scene is live state gathering that cannot leave. Recorded on the PR so
   the reasoning is not lost.
