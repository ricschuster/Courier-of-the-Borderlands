# Session Handoff: 2026-07-28 (v46)

## Summary

Slice 5 of the world expansion, landed in one PR (#447). It settles the two
oldest open design calls, #436 and #412, which turn out to be one question asked
twice: **what a coin is worth against a skill point in the travel sink.** Doing
them separately would have meant tuning twice.

The session's method is worth more than its numbers. Every previous tuning round
here has been a by-feel change measured after the fact by a scripted arc that
plays exactly one build. This one priced the world statically first, which is
what turned two "needs an owner call" issues into a call with numbers attached.

## Completed

- **#436** and **#412** (#447), both closed. Three coordinated changes:
  - Greybridge `wearMultiplier` 1 -> **1.8**
  - Off-road **no longer cuts wear** (`offRoadWearFactor` and its two knobs are
    gone, along with `wearPerTile`'s `offRoadRank` parameter)
  - `wearReliefPerUpgrade` 0.15 -> **0.25**, floor 0.5 -> **0.35**
- **`npm run measure:wear`** (`tests/unit/wear-cost-regions.test.ts`), a static
  report that prices every home-to-settlement leg in every region for eight
  builds. Wired into package.json and the README so it does not rot (trap 5).

## What the measurements said

Three, in order, because each answered something the previous one could not.

**1. The arc run, before anything changed.** Capstone reached with **0 strands,
1319 coins in hand after buying every upgrade in the game (640c)**, wagon full,
51 of 101 samples above 76% condition. The sink neither threatened nor drained.

**2. The static report.** The arc run plays one build, so it cannot say what a
purchase buys. Priced over every leg in all four regions:

| build | before | after |
|---|---|---|
| bare | 217 | 225 |
| axle (60c) | 184 | 168 |
| axle+treads (150c) | 134 | 98 |
| all relief (290c) | 84 | **55** |
| off-road 1 (1 point) | 195 | **225, exactly bare** |
| off-road 3 (3 points) | 103 | 152 |

Before, three skill points bought roughly **290 coins of relief upgrades** on top
of 30% speed and both crossings. That is #412's substitution, finally with a
number on it. And in Greybridge a bare level-1 wagon's worst leg cost 40% of its
tank one way, with everything else under 16%: nothing in the hub had to be
bought, which is #436's hole.

**3. The arc run again, after.** Capstone still reached, so nothing soft-locks:

| | before | after |
|---|---|---|
| strand events | 0 | **2, both in Greybridge** |
| coins at the end | 1319 | **1141** |
| samples at 0 condition | 0 | 4 |

The pressure moved to where #436 asked for it. The hub is now the only region the
scripted driver strands in, on its level-1 tank, and it recovers by towing home
and repairing, which is exactly the cheap failure #433 built. The coin drain rose
about 180 without the repair price moving at all.

## Decisions

**Access is the only thing the two currencies may share.** Two keys to one door
(#95, #103) is a good mechanic and it stays: Off-road rank 2 still opens the
mire, rank 3 the tidal flats. What went wrong is that Off-road *also* cut wear,
so a skill point quietly bought the upgrade's other effect. Points now buy speed
and access, coins buy durability. Recorded in `07_roads_gate_the_wagon.md` so a
future skill effect does not rebuild the substitution by accident.

This was chosen over #412's own options: pricing ranks 2/3 at two points each
(touches the skill panel and every save's point maths) and removing the crossings
(closes a route for players who bought into it). Nothing shipped was removed, and
`tidal-route.spec` and `mire-route.spec` pass unchanged.

**The hub carries the early pressure, and roads stay free.** Roads are roughness
0 and wear nothing at any multiplier, so both roads out of Greybridge cost what
they always did. At 1.8x the two off-road spurs carry it instead: Reedgrave 64%
of the level-1 tank one way, Mirewatch 23%. The wilds ask for the Sprung Axle; no
signpost refuses anyone, so this is not the exit lock #434 removed in a new hat.

**One lever at a time, so the next playtest can attribute.** Repair price stays
at 5c/pt. Repair spend is wear times price, and the wear levers roughly double
mid-build wear on their own, so the drain rises without touching it. The measured
result (-178 coins) confirmed that.

**`wearPerTile` lost a parameter rather than gaining a zeroed knob.** A knob that
is 0 in every preset is a path whose broken and correct behaviour are identical,
which is the shape trap 1 is about. Re-adding it is a git revert away.

## The near-miss worth recording

The three report tests went green under `npm test` and **failed the CI coverage
gate**, because `--coverage` instrumentation roughly octuples routing work and
pushed them past vitest's 5s default. This is the third time that has bitten this
repo (the survey report hit it when Ashmoor was added). `npm test` is not the
gate; `npm run test:coverage` is. Fixed with explicit timeouts, which is the same
fix as last time and is now the convention for any routing analysis test.

Caught locally only because the coverage run was done before pushing rather than
after.

## Risks or decisions needed

- **Demanding no longer finishes the measured arc (#448).** Its 1.67x wear on a
  16-point tank sits on top of the hub's new 1.8x, and the run was killed at the
  spec's 720s budget mid-drive. The failure mode is the reassuring one: no stall,
  no stuck tile, no exhausted step budget, just a wagon crawling at
  `limpSpeed: 0.1`. It is **not baselined** against pre-slice-5, and the static
  numbers say Demanding was already unable to reach Reedgrave on a fresh tank
  (103% of it before, 167% after), so slice 5 deepened a hole rather than digging
  one. Tracked as a design call, because the real question is whether a 10x limp
  is the right price for overreaching on the hard preset, and #433 argued the
  opposite direction.
- **Two strands in the measured arc is a signal, not a verdict.** The scripted
  driver overreaches in ways a person would not, which its own spec documents.
  Read it as an upper bound.
- **Still ~5 minutes of core arc**, unchanged from v45 and v44. Slice 5 tuned the
  sink against the world as it stands; the 25 to 30 minute milestone still needs
  core-arc content, and nothing in this session moved that number.
