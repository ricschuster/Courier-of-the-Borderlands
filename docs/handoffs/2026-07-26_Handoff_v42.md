## Decisions taken

1. **The Wayfinder ring is a margin, not a radius.** `survey = reveal + 2 per
   rank`, so it always reaches past the fog whatever is fitted and whatever the
   weather does. The reveal radius is now computed once in `revealRadiusNow()`
   and shared by fog and ring, so the two cannot silently diverge again, which is
   exactly how the bug arose.
2. **The 0.9.0 release stays held** at the owner's call, now with three
   player-visible changes behind it: the spend gate, the fixed ring, and the
   skill description that never mentioned the ring at all.
3. **A cycle between accessors is not a cycle between functions.** See below.

## The two findings

### The survey ring was inert, not weak

Walked fog reaches `2.5` base + `1.5` Far Lantern + `2` Courier's Charts + `1`
per Wayfinder rank. The ring reached `3` per rank, absolute. **Fitted out, the
ring sat inside the fog at every rank and was exactly equal at rank 3.** It could
not show a single tile the player could not already see.

Both playtests' Wayfinder personas bought all seven upgrades, so the feature
under test was showing them nothing. "Economics unchanged after #341" needed no
appeal to feel at all.

The measurement tool (`npm run measure:survey`) simulates the journey with
re-planning rather than diffing two static paths, because the case that matters
is committing to a corridor that turns out to be blocked.

**The methodological point: my first run measured only the fitted loadout, got
zero, and that zero would have been a true number from an experiment rigged to
produce it.** The suite now pins the configuration where the ring provably
reaches past the fog and must be able to score, so a future zero can be
distinguished from a broken tool.

### #392's blocker did not exist

The survey called the contract cluster blocked by
`boardContracts -> effectiveFlags -> regionCleared -> baseContractCounts ->
completed`. That cycle only exists if something tries to **own** the state. As
pure functions taking their inputs as arguments there is no cycle, just a
derivation, and the scene already held every input. `completed` never had to
move.

The survey scored coupling on the assumption that every cluster wants to become a
state owner. That assumption made this one look impassable for nine slices.
